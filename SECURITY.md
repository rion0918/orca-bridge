# Security policy

Please use [GitHub private vulnerability reporting](https://github.com/rion0918/orca-bridge/security/advisories/new) for issues involving authentication, unintended project access, isolation, approval bypass, or credential exposure.

Include the affected commit, macOS and CLI versions, the configuration needed to reproduce the issue, and the expected and observed behavior. Use a dedicated test project and dummy credentials. Remove live tokens, private code, and reachable endpoints from the report and its attachments.

Reports are triaged against the current `main` branch. If an older commit is affected, include its hash. Use public issues for ordinary bugs.
